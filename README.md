# Personal Portfolio Website

A customized portfolio website showcasing my skills, projects, and learning journey.  
This site is designed to highlight backend development, web design, and competitive coding experience in a clean, responsive format.

## 🚀 Features
- Responsive design for desktop and mobile
- Sections for skills, projects, and contact
- Easy navigation with a professional layout
- Simple structure for quick updates

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Structure
- **index.html** → Homepage with intro and highlights
- **projects.html** → Showcase of completed projects
- **contact.html** → Contact form and links
- **assets/** → Images, stylesheets, and scripts
